# Handoff Template

Use this format when an agent finishes implementation or review.

```text
Agent:
Task:

Changed:
- 

Verification:
- 

Risks / follow-ups:
- 
```

For review-only work, lead with findings:

```text
Agent: qa-review-agent
Review target:

Findings:
- 

Verification gaps:
- 

Suggested owner:
- 
```
